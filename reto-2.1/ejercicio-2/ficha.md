# Ficha del dispositivo

## Dispositivo seleccionado
Teclado

## Tecnología de captura
El teclado detecta cuando una persona presiona o suelta
una tecla. El sistema operativo comunica esa entrada
al programa y Godot la procesa mediante eventos.

## Tipo de señal
Digital.

Se considera digital porque cada tecla tiene dos
estados principales: presionada o liberada.

## Ventaja
Permite controlar las acciones del personaje de
manera sencilla y precisa.

## Limitación
Las teclas no permiten controlar gradualmente
la intensidad del movimiento, como lo hace
un joystick analógico.

## Ejemplo de videojuego
Minecraft, donde el teclado se utiliza para
controlar el movimiento del personaje.
